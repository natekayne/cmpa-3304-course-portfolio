Experimenting with Navigation

I experimented with four different navigation styles throughout this website:

  • class="nav-simple" - vertical list
  • class="nav-horizontal" - horizontal navigation bar
  • class="nav-custom" - centered navigation
  • class="nav-justified" - justified navigation (current)

One thing I really like about using a shared stylesheet is that I can keep my colors, fonts, and hover effects consistent without having to style every page separately. I also kept the same dark purple and red theme from my Personal Landing Page.
