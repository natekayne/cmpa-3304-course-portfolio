Marvel Rivals: Skin Shop Edition

I chose Marvel Rivals because I play it all the time on my PS5. I thought it would be funny to change the homepage to show how expensive buying skins (costumes) can get. My wallet definitely feels it!

What I Changed

Using Chrome DevTools, I changed the headline to "NEW SKINS EVERY SEASON, NO MONEY IN MY ACCOUNT!" I also changed the CSS color to bright pink, made the font size 30px, and centered the text. I removed the original background image from that section so my new text would show up.

I thought it was pretty cool seeing how I could change the HTML and CSS without actually changing the real website. It helped me understand how DevTools can be useful when testing different designs and fixing things on my own webpages.
